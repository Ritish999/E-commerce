# 🛍️ Hamro Storee – E-Commerce Website

Hamro Storee is a front-end e-commerce website designed to provide users with a simple and enjoyable online shopping experience. Users can explore different product categories through a clean and user-friendly interface.

## 🚀 Features

- 🏠 Clean and user-friendly homepage
- 👕 Men's and women's product sections
- 🎒 Gear and accessories collection
- 👖 Workwear collection
- 🛒 Shopping cart interface
- 🔐 Login page
- 📱 Organized product pages
- 🎨 Responsive and attractive UI design

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Website functionality
- **Remix Icons** – Icons

## 💻 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/Ritish999/E-commerce.git
```

2. Open the project folder:

```bash
cd E-commerce
```

3. Open `ecomm.html` in your browser.

You can also use the **Live Server** extension in VS Code.
